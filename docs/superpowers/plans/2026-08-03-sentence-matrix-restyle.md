# Sentence Matrix Restyle Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restyle the Sentence Matrix as an unnumbered vertical transformation rail and emphasize authored comparison-slot tokens in Japanese and romaji without changing lesson behavior, content order, localization, or answer-metadata boundaries.

**Architecture:** `buildLessonViewModel.ts` remains the single source of localized matrix rows and derives ordered comparison token IDs strictly from family-slot source metadata. `SentenceMatrix.tsx` consumes that view-model field through the existing Japanese segment renderer and `RomajiSequence` highlighting API, while `foundation.css` provides the presentation-only rail, surfaces, hierarchy, badges, and non-color-only emphasis. Vitest locks the data and DOM contracts; Playwright locks computed emphasis, responsive/zoom behavior, metadata safety, and the two reviewed visual baselines.

**Tech Stack:** TypeScript, React 19, Vitest with jsdom, CSS custom properties, Playwright Chromium, Vite

## Data-flow and API decision

The approved public signature is implementable without divergence:

```ts
export function foundationComparisonTokenIds(
  family: SentenceFamily,
  variant: SentenceVariant,
  tokens: readonly AssembledToken[],
): readonly string[];
```

`rowFor` already resolves `sentence` and `variant`, and its existing `Index` already exposes `familyById`. Resolve `familyById.get(variant.sentenceFamilyId)`, preserve the existing `null`/`realization-failed` path when it is absent, and call the approved helper with `sentence.tokens`. No extra public lookup, overloaded signature, or catalog access from `SentenceMatrix` is required.

The test oracle boundary is equally strict:

- Pure-helper tests use hard-coded expected IDs from crafted token metadata; they do not calculate the expected result by reimplementing the parser.
- Fixture/production coverage checks non-empty ordered subsets and locale/order preservation; it does not derive expected IDs from the helper's own output.
- Component and Playwright tests use the already-verified `row.comparisonTokenIds` only to select expected visible token text. They never serialize IDs into DOM attributes and never discover expected IDs by reading rendered marks.

## Constraints and non-goals

- Preserve exactly three curated rows when collapsed and all eight authored rows
  when expanded; never reorder by locale, script, token value, or visual
  similarity.
- Preserve IT/EN copy, hiragana/romaji behavior, native disclosure state,
  semantic section/list/definition-list/button structure, visible focus, and
  reduced-motion behavior.
- Keep the rail unnumbered and vertical at every width. Do not add ordered-list
  semantics, numeric markers, timeline/step language, horizontal scrolling,
  study-card columns, or anonymous table bands.
- Do not infer comparison content from Japanese, romaji, translations, adjacent
  rows, or string diffs.
- Do not expose canonical Japanese, romaji, comparison IDs, or answer material
  in DOM metadata.
- Do not change guided-construction behavior, authored catalogs, course content,
  exercise selection, routes, persistence, unrelated course styling, or add a
  new learning mode.

```ts
function authoredFamilySlotId(
  token: AssembledToken,
  variantId: string,
): string | undefined {
  if (token.source.domain !== "family") return undefined;
  const segments = token.source.referenceId.split("/");
  if (segments.length !== 2 || segments[0] !== variantId) return undefined;
  return segments[1] || undefined;
}

export function foundationComparisonTokenIds(
  family: SentenceFamily,
  variant: SentenceVariant,
  tokens: readonly AssembledToken[],
): readonly string[] {
  const familySlotIds = new Set(family.slotSchema.map((slot) => slot.id));
  return tokens
    .filter((token) => {
      const slotId = authoredFamilySlotId(token, variant.id);
      return (
        slotId !== undefined &&
        familySlotIds.has(slotId) &&
        Object.prototype.hasOwnProperty.call(variant.slotValues, slotId)
      );
    })
    .map((token) => token.id);
}
```

```ts
function renderDocument(
  locale: "en" | "it",
  script: "hiragana" | "romaji" = "hiragana",
): Document {
  return new DOMParser().parseFromString(render(locale, script), "text/html");
}

function visibleJapaneseText(element: Element): string {
  const clone = element.cloneNode(true) as Element;
  clone.querySelectorAll("rt").forEach((reading) => reading.remove());
  return clone.textContent ?? "";
}

function expectedRomajiMarks(
  row: FoundationLocalizedRow,
): readonly string[] {
  const formatted = formatRomaji(row.tokens);
  if (!formatted.ok) throw new Error(`invalid romaji for ${row.variantId}`);
  const selected = new Set(row.comparisonTokenIds);
  return formatted.runs
    .filter((run) => selected.has(run.tokenId))
    .map((run) => run.text);
}
```
