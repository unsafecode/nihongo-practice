# Phase 2 Deep A1 Rewrite and V4 Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the 40-lesson scaffold with an exact 12-module, 48-lesson A1 course that satisfies every Phase 1 depth invariant, preserves safe visited progress through an idempotent V3-to-V4 migration, and exposes four A1 synthesis scenarios plus separate checkpoint evidence.

**Architecture:** A new `src/course/a1` release catalog reuses the Phase 1 semantic family, realization, deterministic selection, exercise, validation, report, matrix, guided, and two-round UX primitives. Content is authored in four-module slices behind module-local gates; only after all 48 lessons pass the full A1 validator does the runtime switch from the legacy catalog, followed by an atomic browser-only V4 progress migration and public route/E2E integration.

**Tech Stack:** React 18, TypeScript 5.6, Vitest 3, Phase 1 foundation engine, existing browser speech adapters, React Router 7, localStorage, Playwright, Vite/GitHub Pages

## Fixed A1 lesson manifest

Every module has exactly four lessons. Existing published IDs are preserved when
the practical objective remains safe; nine new IDs fill the depth gaps, and
`sounds-5` becomes a reviewed legacy alias for the consolidated `sounds-4`.

| Module | Lesson IDs and practical outcomes |
|---|---|
| `sounds` | `sounds-1` core mora/vowels; `sounds-2` gojūon, dakuten, and yōon; `sounds-3` small っ, long vowels, and sound contrasts; `sounds-4` supported high-frequency katakana in familiar expressions |
| `introductions` | `introductions-1` name and role; `introductions-2` origin, country, and language; `introductions-3` occupation, study, and work; `introductions-4` reciprocal personal details with natural subject omission |
| `essential-questions` | `essential-questions-1` demonstratives and which; `essential-questions-2` who/what/where; `essential-questions-3` when, quantity, and price; `essential-questions-4` clarification and reciprocal short questions |
| `actions` | `actions-1` polite present object actions; `actions-2` action place with で; `actions-3` companion/person roles and omitted subjects; `actions-4` transfer across object, place, and person |
| `routines` | `routines-1` clock time; `routines-2` days and sequence; `routines-3` frequency; `routines-4` a short daily routine |
| `past-negative` | `past-negative-1` verbal past; `past-negative-2` verbal negative; `past-negative-3` past negative; `past-negative-4` nominal/adjectival tense and polarity |
| `places` | `places-1` destinations with に/へ; `places-2` transport with で; `places-3` departure, arrival, から/まで; `places-4` route questions and actions at places |
| `people` | `people-1` family and relationships; `people-2` roles and limited personal information; `people-3` shared actions and invitations; `people-4` reciprocal social details |
| `descriptions` | `descriptions-1` familiar い/な descriptions; `descriptions-2` likes and dislikes; `descriptions-3` bounded comparison and choice; `descriptions-4` weather and immediate conditions |
| `shopping` | `shopping-1` prices and basic counters; `shopping-2` quantities and choosing; `shopping-3` bounded polite requests; `shopping-4` a short purchase exchange |
| `existence-needs` | `existence-needs-1` animate/inanimate existence; `existence-needs-2` position relations; `existence-needs-3` immediate needs and wants; `existence-needs-4` locate something and resolve a practical need |
| `capstones` | `capstones-1` self-introduction; `capstones-2` daily outing; `capstones-3` travel day; `capstones-4` supported mixed dialogue with one topic change |
